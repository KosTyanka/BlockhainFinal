# AI Model Marketplace - Blockchain Final Project

## Overview
This project is a decentralized AI Model Marketplace where users can:
- List AI models for sale.
- Buy AI models using ERC-20 tokens (AITUSE2321).
- Connect MetaMask to interact with the smart contracts.

## Features
 Connect MetaMask  
 Display ERC-20 Token Balance  
 List AI Models for Sale  
 Buy AI Models with Tokens  

## 🔹 Technologies Used
- **Solidity** (Smart Contracts)
- **Hardhat** (Ethereum development)
- **React.js** (Frontend)
- **Ethers.js** (Blockchain interaction)
- **MetaMask** (Wallet Integration)
